# Experiment 5 - Java JDBC CRUD

This folder is integrated into the Smart Water Experiment 4 project so all files are inside one project folder.

## Requirements
- Java JDK
- MySQL Server
- MySQL Connector/J

## Database
Run `schema.sql` in MySQL first.

## Java files
- `src/DBConnection.java` - JDBC database connection
- `src/SmartWaterCRUD.java` - CRUD menus for monitoring stations, water-quality measurements, and alerts

## Run
Compile the Java files with MySQL Connector/J on the classpath, then run `SmartWaterCRUD`.

The original Experiment 4 web files remain in the parent folder.
